Panduan Install PWA

Kenapa perlu install PWA?

Browser block audio bila tab minimize. Dengan PWA, notification OS + bunyi native berfungsi walaupun app di-minimize.

Cara Install (Chrome / Edge):

  1. Klik ikon Install (⊕) di address bar, ATAU klik button INSTALL PWA.
  2. Klik Install pada popup yang muncul.
  3. App akan terbuka dalam window tersendiri (standalone mode).
  4. Shortcut akan dibuat di desktop — buka dari situ.

✅ Selepas PWA: Notification popup + bunyi OS muncul walaupun app di-minimize.
